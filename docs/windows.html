Windows

For Windows 10 and 11, 64-bit and ARM.

Install

PowerShell (recommended)

irm https://kothalipi.tashanto.com/install.ps1 | iex

Installs for your user account (no administrator rights) and opens Kothalipi.

Installer

  1. Download the -setup.exe from the download page.
  2. Run it and follow the steps.

“Windows protected your PC”: early releases are not code-signed yet, so SmartScreen warns you. Click More info, then Run anyway.

Microphone

If Kothalipi cannot hear you: Settings → Privacy & security → Microphone, turn on Microphone access and Let desktop apps access your microphone.

Keys

Bangla: Right Alt. English: Right Ctrl. On some layouts Right Alt is AltGr; choose another key in Settings → General if it gets in the way. Apps running as administrator block typing from other apps; run Kothalipi as administrator too if you need it there.

Uninstall

Settings → Apps → Installed apps → Kothalipi → Uninstall.
