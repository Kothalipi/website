Windows

For Windows 10 and 11, 64-bit and ARM.

Install

PowerShell (recommended)

irm https://kothalipi.tashanto.com/install.ps1 | iex

Installs for your user account (no admin rights needed) and opens Kothalipi.

Installer

  1. Download the -setup.exe from the download page.
  2. Run it and follow the steps.

“Windows protected your PC”: early releases aren't code-signed yet, so SmartScreen warns you. Click More info, then Run anyway.

Microphone

If Kothalipi can't hear you: Settings → Privacy & security → Microphone, turn on Microphone access and Let desktop apps access your microphone.

Keys

Bangla: Right Alt. English: Right Ctrl. Some apps running as administrator block typing from other apps; run Kothalipi as administrator too if you need it there.

Uninstall

Settings → Apps → Installed apps → Kothalipi → Uninstall.
