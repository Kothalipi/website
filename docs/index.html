Getting started

From download to your first Bangla sentence in about five minutes.

1. Install

Download from the download page, or use the terminal:

macOS and Linux
curl -fsSL https://kothalipi.tashanto.com/install.sh | sh
Windows (PowerShell)
irm https://kothalipi.tashanto.com/install.ps1 | iex

Platform details: macOS · Windows · Linux.

2. Follow the setup

  1. Permissions. Allow the microphone. On a Mac, also allow Accessibility so Kothalipi can type into other apps.
  2. Choose how it listens. Offline is free and private. Cloud uses your own Gemini or ChatGPT key and is the most accurate. Low-memory computers are steered to Cloud. See Cloud & API keys.
  3. Download the voice models. Setup recommends the best Bangla and English model for your computer. In Cloud mode they are your offline backup.
  4. Check your keys. On a Mac, Kothalipi spots macOS settings that steal the keys and opens the right page.
  5. Try it. Hold the Bangla key, speak, let go.

3. Use it anywhere

macOSWindowsLinux
বাংলাRight ⌘Right AltCtrl+Alt+B
EnglishfnRight CtrlCtrl+Alt+E

Hold the key while you talk, or tap once to start and again to stop. Change keys in Settings → General.
