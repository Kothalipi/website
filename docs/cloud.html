Cloud & API keys

Cloud mode sends your recording directly to the AI provider you choose using your own API key. It gives the highest accuracy for Bangla, Banglish, and live Bangla-to-English translation — completely free with Gemini and Groq.

How automatic fallback works

Kothalipi tries your configured engines in order: Google Gemini → Groq Whisper (Free) → OpenAI → Offline. If one provider hits its free rate limit, fails, or you lose internet, Kothalipi automatically switches to the next engine so your typing never stops.

1. Get a free Google Gemini API key (Recommended)

  1. Open Google AI Studio → API keys and sign in with your Google account.
  2. Click Create API key and copy the key (starts with AIzaSy...).
  3. On Desktop: Open Settings → General → Listening → choose Cloud (your keys) → paste under Google Gemini → click Save.
  4. On Mobile (Android / iOS): Open ⚙️ Settings → paste under Google Gemini API Key → tap Test → tap Save.

Gemini includes a generous free tier with daily limits. Full walkthrough: Free Gemini API key guide →

2. Get a free Groq Whisper API key (Ultra-Fast Backup)

  1. Open console.groq.com/keys and sign in with Google or GitHub (free, no card required).
  2. Click Create API Key, name it Kothalipi, and copy the key (starts with gsk_...).
  3. On Desktop (v0.1.8+): Paste under Groq Whisper (Free, Ultra-Fast) in Settings → General → Listening and click Save.
  4. On Mobile (v0.2.0+): Paste under Groq Whisper Key in ⚙️ Settings, tap Test, and tap Save.

Powered by whisper-large-v3-turbo on Groq LPUs for sub-second speed. Full walkthrough: Free Groq Whisper key guide →

3. Optional: Add an OpenAI (ChatGPT) key

  1. Create a key at platform.openai.com/api-keys (paid per minute of audio).
  2. Paste it under OpenAI (ChatGPT) in Desktop or Mobile Settings and click Save / Test.

What about Claude?

Claude does not take audio input, so it cannot turn speech into text. On Desktop, it can polish your text afterwards in Settings → Post-Processing with your Anthropic API key.

Privacy: where your keys and audio go

  • Your API keys are stored locally on your computer or phone and sent only to their respective provider.
  • Audio goes straight from your device to Google, Groq, or OpenAI. Kothalipi has no middleman servers.
  • Offline mode sends nothing anywhere.
