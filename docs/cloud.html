Cloud & API keys

Cloud mode sends your recording to the provider you choose, using your own key. It is the most accurate option, especially when you mix Bangla and English.

If a key is over its limit, rejected, the provider is down, or you have no internet, Kothalipi moves to the next one. When every cloud key fails it uses your offline model. With no offline model either, it asks you to download one, so keep the Bangla model downloaded as a backup.

Get a free Gemini key

  1. Open Google AI Studio → API keys and sign in with a Google account.
  2. Click Create API key and copy it.
  3. In Kothalipi: Settings → General → Listening, choose Cloud, paste the key under Google Gemini and click Check & Save.

Gemini has a free tier with daily limits. Usage above it is billed by Google to your account. Kothalipi uses the gemini-3.5-transcribe model by default; you can change it in Settings.

Add a ChatGPT (OpenAI) key

  1. Create a key at platform.openai.com/api-keys. OpenAI's API is paid per minute of audio.
  2. Paste it under OpenAI (ChatGPT) and click Check & Save.

Default model: gpt-transcribe. Use the arrows in Settings to try OpenAI before Gemini.

What about Claude?

Claude doesn't take audio input, so it can't turn speech into text. It can polish the text afterwards (fix spelling, punctuation, tone): set it up in Settings → Post-Processing with your Anthropic API key.

Where your keys and audio go

  • Keys are stored in Kothalipi's settings on your computer and sent only to their provider.
  • Audio goes straight from your computer to that provider. It never passes through Kothalipi's servers; there are none.
  • Offline mode sends nothing anywhere.
