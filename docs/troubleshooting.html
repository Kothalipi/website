Troubleshooting

Nothing happens when I hold the key

  • Mac: check Accessibility is on for Kothalipi (guide), and fix key conflicts.
  • Make sure Kothalipi is running (menu bar or system tray icon).
  • Try the other key, or set a new one in Settings → General.

It hears me but types nothing

  • Click into a text field first; the text goes where your cursor is.
  • Check the microphone in Settings → Sound.

Wrong words in Bangla

  • Use the Bangla key, not the general Transcribe key.
  • Download Bangla · Qwen3-ASR 0.6B in Settings → Models.
  • For mixed Bangla and English, Cloud mode with a Gemini key is the most accurate.
  • Tell us: report wrong words.

Cloud stopped working

Your key may be over its daily limit. Kothalipi falls back to offline automatically; add a second key or wait for the limit to reset. Check the key in Settings → General → Listening.
