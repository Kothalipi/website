Linux

x86_64 and ARM64. Works best on X11; Wayland needs a typing helper.

Install

Terminal (picks .deb, .rpm or AppImage for you)
curl -fsSL https://kothalipi.tashanto.com/install.sh | sh

Manually

Debian / Ubuntu
sudo apt install ./Kothalipi_*_amd64.deb
Fedora
sudo dnf install ./Kothalipi-*.x86_64.rpm
AppImage
chmod +x Kothalipi_*_amd64.AppImage && ./Kothalipi_*_amd64.AppImage

Wayland

Wayland has no standard way for one app to type into another. Install a helper:

wtype
sudo apt install wtype      # wlroots compositors (Sway, Hyprland…)

On GNOME (Ubuntu 26.04+), use ydotool with its service enabled. Global keys on Wayland are set in your desktop's keyboard settings: bind a custom shortcut to handy --toggle-transcription.

Missing libraries

If it won't start with libgtk-layer-shell.so.0 missing:

sudo apt install libgtk-layer-shell0
