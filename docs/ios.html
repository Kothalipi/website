iPhone / iOS

Minimalist voice dictation for iPhone with a custom SwiftUI Voice Hub, system keyboard extension, 3 dictation modes (Bangla, English, and Bangla-to-English translation), and Action Button integration. Requires iOS 16.0 or newer.

1. Download the IPA & Source Code

Download the iOS package: Download Kothalipi-v0.1.0.ipa

The IPA is also mirrored on GitHub Releases (v0.1.6) and the Download page.

2. How to Install on your Physical iPhone (আপনার আসল আইফোনে ইনস্টল)

হ্যাঁ, ১০০% আপনার নিজের আইফোনে ইনস্টল করা যাবে! অ্যাপল কোনো পেইড ডেভেলপার অ্যাকাউন্ট ছাড়াই ব্যক্তিগত ব্যবহারের জন্য নিজের ফোনে অ্যাপ ইনস্টল করার সম্পূর্ণ সুযোগ দেয়। নিচে সবচেয়ে সহজ ৩টি উপায় দেওয়া হলো:

উপায় ১: সরাসরি আপনার Mac ও Xcode দিয়ে (সবচেয়ে সহজ ও ফ্রি ⭐️)

  1. USB ক্যাবল দিয়ে আপনার আসল iPhone-টি Mac-এর সাথে কানেক্ট করুন।
  2. আইফোনের Settings → Privacy & Security → Developer Mode অন করুন এবং ফোনটি একবার রিস্টার্ট দিন।
  3. আপনার Mac-এর টার্মিনালে এই কমান্ড দিয়ে Xcode ওপেন করুন:
cd kothalipi-mobile/ios && xed .
  1. Xcode উইন্ডোর উপরে ডিভাইস ড্রপডাউনে "My Mac" বা সিমুলেটরের জায়গায় আপনার কানেক্টেড iPhone সিলেক্ট করুন।
  2. Signing & Capabilities ট্যাবে গিয়ে আপনার ব্যক্তিগত Apple ID (Personal Team) সিলেক্ট করুন (এটি সম্পূর্ণ ফ্রি)।
  3. উপরে ▶️ (Run) বাটনে চাপুন বা কিবোর্ডে Cmd+R চাপুন।
  4. অ্যাপটি সরাসরি আপনার আইফোনে ইনস্টল হয়ে ওপেন হয়ে যাবে!

প্রথমবার রান করার পর: আইফোনের Settings → General → VPN & Device Management-এ গিয়ে আপনার Apple ID-তে ট্যাপ করে Trust চাপুন।

উপায় ২: AltStore বা SideStore দিয়ে (ক্যাবল ছাড়া)

যদি কম্পিউটারের সাথে না লাগিয়ে নিজের ফোনেই সবসময় অ্যাপ ইনস্টল ও সাইডলোড রাখতে চান:

  1. আইফোনে AltStore অথবা SideStore সেটআপ করে নিন।
  2. আমাদের রিলিজ পেইজ থেকে Kothalipi-v0.1.0.ipa ফাইলটি Safari দিয়ে ডাউনলোড করুন।
  3. AltStore অ্যাপে গিয়ে My Apps → “+” বাটনে চাপ দিয়ে ডাউনলোড করা IPA ফাইলটি সিলেক্ট করুন। আপনার নিজস্ব Apple ID দিয়ে অ্যাপটি সাইন হয়ে ফোনে ইনস্টল হয়ে যাবে।

উপায় ৩: TrollStore (iOS 14.0 – 16.6.1)

যদি আপনার আইফোনে iOS 14.0 থেকে 16.6.1 এর মধ্যে থাকে এবং TrollStore ইনস্টল থাকে, তবে কোনো ৭ দিনের রিনিউয়াল ঝামেলা ছাড়াই পার্মানেন্টলি Kothalipi IPA এক ক্লিকে ইনস্টল করে আজীবন ব্যবহার করতে পারবেন।

3. ৩টি ডিকটেশন মোড (Dictation Modes)

কথালিপি মোবাইলে রয়েছে এক ক্লিকে মোড পরিবর্তনের সুবিধা:

  • 🇧🇩 বাংলা: আপনি মুখে যা বলবেন, তা খাঁটি বাংলা হরফে নিখুঁতভাবে টাইপ হবে।
  • 🇬🇧 English: শুধুমাত্র ইংরেজিতে মুখে কথা বলে সরাসরি ইংলিশ টেক্সট টাইপ হবে।
  • বাংলা ➔ 🇬🇧 English (Live Translation): কথ্য বাংলায় স্বাভাবিকভাবে কথা বলবেন (যেমন: “আজকের মিটিংটা কালকে নিলে ভালো হতো”), আর ব্যাকরণগতভাবে শতভাগ নির্ভুল প্রফেশনাল ইংরেজিতে টাইপ হয়ে যাবে (“It would be better if we could reschedule today's meeting to tomorrow.”)।

4. Enable the Voice Keyboard Extension

iOS অন্যান্য অ্যাপের ওপর ফ্লোটিং বাবল অনুমতি দেয় না, তাই কথালিপিতে রয়েছে আল্ট্রা-স্লিক ভয়েস কিবোর্ড এক্সটেনশন:

  1. iPhone Settings → General → Keyboard → Keyboards এ যান।
  2. Add New Keyboard… এ ট্যাপ করে Kothalipi সিলেক্ট করুন।
  3. কিবোর্ড লিস্টে Kothalipi তে ট্যাপ করে Allow Full Access অন করে দিন।

কেন Full Access প্রয়োজন: iOS পলিসির কারণে কিবোর্ড এক্সটেনশন থেকে মাইক্রোফোন ও নেটওয়ার্ক রিকোয়েস্ট এক্সেস করতে "Full Access" লাগে। কথালিপি সম্পূর্ণ প্রাইভেট এবং কোনো কি-স্ট্রোক রেকর্ড বা সেন্ড করে না।

5. Action Button & Back Tap (১-ক্লিক ট্রিগার)

যদি আপনার iPhone 15 Pro, 15 Pro Max, 16 বা 16 Pro থাকে, তবে পাশের Action Button টিকেই ভয়েস টাইপিং বাটনে রূপান্তর করতে পারবেন:

  1. iPhone-এর Shortcuts অ্যাপ ওপেন করুন।
  2. + চাপুন, “Open Kothalipi” শর্টকাট যুক্ত করুন।
  3. Settings → Action Button-এ গিয়ে Shortcut সিলেক্ট করে কথালিপি বেছে নিন।
  4. যেকোনো সময় অ্যাকশন বাটন এক চাপেই কথা বলা শুরু করতে পারবেন!

অন্যান্য আইফোনের জন্য: Settings → Accessibility → Touch → Back Tap-এ গিয়ে Double Tap-এ কথালিপি শর্টকাট সিলেক্ট করে রাখতে পারেন।

6. Google Gemini API Key সেটআপ (সম্পূর্ণ ফ্রি)

কথালিপি অ্যাপের সেটিংস আইকনে ট্যাপ করে আপনার ফ্রি Google Gemini API Key বসিয়ে দিন (ফ্রি কি পাওয়ার গাইড)। আপনার ভয়েস অডিও সরাসরি গুগল এআই স্টুডিওর ফ্রি এন্ডপয়েন্টে প্রসেস হবে—কোনো থার্ড-পার্টি বা মিডলম্যান সার্ভার নেই।
