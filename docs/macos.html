macOS

For Apple Silicon (M1 or newer) and Intel Macs on macOS 10.15 or later.

Install

Terminal (recommended)

curl -fsSL https://kothalipi.tashanto.com/install.sh | sh

Installs Kothalipi.app into Applications and opens it.

Disk image

  1. Download the .dmg from the download page.
  2. Open it and drag Kothalipi into Applications.
  3. Open Kothalipi from Applications.

“Apple could not verify Kothalipi…” Early releases aren't notarized by Apple yet. Open System Settings → Privacy & Security, scroll down and click Open Anyway next to Kothalipi, then confirm. You only do this once. The terminal installer avoids this step.

Permissions

Kothalipi asks for two permissions during setup:

PermissionWhyWhere
MicrophoneTo hear you while you hold a key. Nothing is recorded otherwise.System Settings → Privacy & Security → Microphone
AccessibilitySo the keys work in every app and Kothalipi can type where your cursor is.System Settings → Privacy & Security → Accessibility

If a switch is off, turn on Kothalipi in that list. If it isn't listed, click + and add it from Applications.

Fix key conflicts

Two macOS settings can steal Kothalipi's default keys. The setup checks both and opens Keyboard settings for you.

  1. Globe (🌐/fn) key: System Settings → Keyboard → set “Press 🌐 key to” to Do Nothing.
  2. Dictation shortcut: System Settings → Keyboard → Dictation → Shortcut: choose anything other than “Press Right Command Key Twice” or the 🌐 key, or turn it Off.

Or change Kothalipi's keys instead, in Settings → General.

Uninstall

rm -rf /Applications/Kothalipi.app "$HOME/Library/Application Support/com.kothalipi.desktop"
