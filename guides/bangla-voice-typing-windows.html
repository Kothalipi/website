How to type Bangla with your voice on Windows

Dictate Bangla into any Windows app with Kothalipi, free and offline, on Windows 10 and 11.

Updated 2026-11-22 · 4 min read

1. Install Kothalipi

Open PowerShell and run:

irm https://kothalipi.tashanto.com/install.ps1 | iex

It installs for your user account, with no administrator rights. Or download the -setup.exe from the download page and run it.

“Windows protected your PC”: early releases are not code-signed yet, so SmartScreen warns you. Click More info, then Run anyway.

2. Allow the microphone

Setup asks for microphone access. If it is blocked, open Settings → Privacy & security → Microphone and turn on Microphone access and Let desktop apps access your microphone.

3. Download the Bangla model

Choose Offline and download Qwen3-ASR 0.6B Bangla (about 811 MB), or choose Cloud with a free Gemini key (guide). Setup reads your memory and recommends the best option.

4. Use the keys

Hold Right Alt for Bangla and Right Ctrl for English. Hold while you speak and let go to type, or tap once to start and again to stop.

On some keyboard layouts Right Alt acts as AltGr and is used to type symbols. If that gets in the way, choose a different key in Settings → General.

Good to know

  • Windows blocks typing from a normal app into windows running as administrator. Run Kothalipi as administrator too if you need that.
  • On Windows on ARM, the ARM installer is used automatically.
  • To uninstall: Settings → Apps → Installed apps → Kothalipi.

More in the Windows guide and troubleshooting.
