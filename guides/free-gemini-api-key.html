Get a free Gemini API key for Bangla voice typing

Cloud mode uses your own Google Gemini key. It is the most accurate choice for Bangla, especially when you mix Bangla and English.

Updated 2026-11-23 · 3 min read

1. Create the key

  1. Open Google AI Studio → API keys and sign in with a Google account.
  2. Click Create API key and copy it.

In Kothalipi's setup, the Get a free key button opens the same page.

2. Add it to Kothalipi

  1. Open Settings → General → Listening and choose Cloud (your keys).
  2. Paste the key under Google Gemini and click Check & Save. Kothalipi checks the key before saving it.
  3. Hold your Bangla key and speak.

Kothalipi uses the gemini-3.5-transcribe model by default. You can change the model name in the same settings.

What if the limit runs out?

The free tier has daily limits. When Gemini refuses a request, Kothalipi automatically tries the next engine you enabled — such as Groq Whisper (Free) (get a free Groq key) or OpenAI — and when every cloud engine fails or you are offline, it falls back to your offline model. Keep the Bangla model downloaded (or Offline Mode ready on Mobile) so dictation never stops.

Optional: a second free provider (Groq Whisper)

Add a free Groq Whisper key (console.groq.com/keys) for ultra-fast whisper-large-v3-turbo transcription, or an OpenAI key as a paid backup.

Privacy

  • Your key is stored on your computer or phone and sent only to its provider.
  • Audio goes straight from your device to Google/Groq/OpenAI. It never passes through Kothalipi, which has no servers.
  • Read Google's Gemini API terms: on unpaid tiers they can allow submitted content to be used to improve Google products. For anything sensitive, use Offline mode.

Claude cannot transcribe audio, so it is not a speech engine here. It can polish your text afterwards in Settings → Post-Processing.
