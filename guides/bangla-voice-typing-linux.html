How to type Bangla with your voice on Linux

Dictate Bangla on Linux with Kothalipi. It works best on X11; Wayland needs a small typing helper.

Updated 2026-11-22 · 4 min read

1. Install

One line: picks .deb, .rpm or AppImage for you
curl -fsSL https://kothalipi.tashanto.com/install.sh | sh
Debian and Ubuntu
sudo apt install ./Kothalipi_*_amd64.deb
Fedora
sudo dnf install ./Kothalipi-*.x86_64.rpm
AppImage (any distribution)
chmod +x Kothalipi_*_amd64.AppImage && ./Kothalipi_*_amd64.AppImage

If it will not start and mentions libgtk-layer-shell.so.0, install it: sudo apt install libgtk-layer-shell0.

2. Allow typing into other apps

X11

Nothing to do. Kothalipi types through the X server.

Wayland

Wayland has no standard way for one app to type into another, so install a helper:

wlroots compositors such as Sway and Hyprland
sudo apt install wtype

On GNOME (for example Ubuntu 26.04), use ydotool with its service enabled.

3. Download the model and set your keys

Follow setup: choose Offline and download the Bangla model, or Cloud with a Gemini key. Default keys are Ctrl+Alt+B for Bangla and Ctrl+Alt+E for English.

On Wayland, global keys are set in your desktop's keyboard settings. Bind a custom shortcut to kothalipi --toggle-transcription.
