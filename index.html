Questions

Is it really free?

Yes. No account, no trial, no card. Offline mode costs nothing to run. Cloud mode uses your own key; Google Gemini has a free tier with daily limits, billed by Google to you if you go over.

Where do my recordings go?

Offline: nowhere. Cloud: only to the provider you chose (Google or OpenAI), never to us.

Which computers does it run on?

macOS (Apple Silicon and Intel), Windows 10 and 11, and Linux. Android and iOS are coming.

Does it work in every app?

Anywhere you can type: chat, email, browsers, documents, code editors.

Can I change the keys?

Yes, in the app's Settings → General.
