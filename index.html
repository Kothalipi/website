Questions

Is Kothalipi really free?

Yes. It is free and open source under the MIT license, with no account, trial or card. Offline mode costs nothing to run. Cloud mode uses your own API key: Google Gemini has a free tier with daily limits, and OpenAI bills per minute of audio.

Does Bangla voice typing work offline?

Yes. Offline mode runs a Bangla speech model on your computer, so it works without internet and your voice never leaves the machine. You download the model once (about 810 MB).

How accurate is it for Bangla?

It depends on the model. The recommended offline model, Qwen3-ASR 0.6B Bangla, was trained on 1,174 hours of Bangla speech and its authors report 14.74% word error rate and 5.34% character error rate on their own test set. Cloud mode with Google Gemini is usually best when you mix Bangla and English. We are building a public benchmark and will publish results.

Can I mix Bangla and English in one sentence?

Yes, that is a design goal. Use the Bangla key for sentences with English words in them. Cloud mode handles mixed speech best.

Which computers does it run on?

macOS 10.15 or later (Apple Silicon and Intel), Windows 10 and 11 (x64 and ARM) and Linux (.deb, .rpm and AppImage; X11 and Wayland). Android and iOS keyboards are planned.

Where do my recordings go?

In offline mode, nowhere: audio is turned into text on your computer. In cloud mode, a recording is sent only to the provider whose key you added (Google or OpenAI), never to Kothalipi. Kothalipi has no servers, accounts or analytics.

Do I need an API key?

Only for cloud mode. Offline mode needs no key. Get a free Gemini key in about a minute: see the free Gemini API key guide.

What happens when my API limit runs out or I lose internet?

Kothalipi tries your engines in order (Gemini, then OpenAI) and then falls back to the offline model automatically, so dictation keeps working.

Does it work in every app?

It types where your cursor is, so it works in chat apps, email, browsers, documents and code editors. Some apps running as administrator (Windows) or with secure input (macOS) can block typing.

Who makes Kothalipi?

Kothalipi is made by TA Shanto in Bangladesh. The speech engine began from the open-source Handy project by CJ Pais (MIT); see the credits.
