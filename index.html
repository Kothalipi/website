Why Kothalipi

Built for Bangla

Most voice typing tools run models that struggle with Bangla. Kothalipi uses models fine-tuned on Bangla speech, and we test them on a public benchmark anyone can check.

Private by default

Speech recognition runs on your computer. Your voice never leaves it unless you turn on a cloud engine with your own key.

Fully open source

Every line of code is public under the MIT license. No account, no trial, no hidden data collection.

Every platform

macOS, Windows and Linux first, then Android and iOS keyboards.

Questions

Is it free?

Yes. Kothalipi is open source under the MIT license. Offline mode costs nothing to run. If you choose a cloud engine, you use your own API key with that provider.

When can I download it?

We are building the first desktop version now. Watch the GitHub repo to get notified when the first release is out.

Where do my recordings go?

Nowhere. In offline mode audio is processed on your device and discarded. Cloud mode is optional and always off by default.

Can it handle Bangla mixed with English?

That is a core goal. Mixed speech is part of our test set from day one, and we publish how each model does.

Will it support other languages?

Yes. Bangla comes first, and the project is designed so any community can add its language, including romanized forms like Hinglish or Arabizi.
