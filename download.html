        Install from the terminal

        One line. It downloads the latest release from GitHub and installs it.

        macOS and Linux
        curl -fsSL https://kothalipi.tashanto.com/install.sh | sh
        Windows (PowerShell)
        irm https://kothalipi.tashanto.com/install.ps1 | iex

        Read the scripts first if you like: install.sh · install.ps1

        Early releases are not code-signed yet. macOS and Windows may show a warning the first time. It is safe to continue, and the guides show how: macOS · Windows. The terminal installer avoids the macOS prompt.

        Requirements

        macOS10.15 or later, Apple Silicon or Intel. About 1 GB free for the Bangla model.
        WindowsWindows 10 or 11, 64-bit or ARM. About 1 GB free for the Bangla model.
        LinuxA recent 64-bit distribution with GTK 3 and ALSA or PipeWire. Wayland needs wtype or ydotool.
        Memory8 GB recommended for offline mode. With 4 GB, use Cloud mode.

        After installing, follow the getting started guide. Every version and its files are on GitHub Releases.
